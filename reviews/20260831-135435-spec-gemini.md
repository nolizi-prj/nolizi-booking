## 2. Coherence and Internal Consistency

- **Single Execution Authority ([`L-007`](file:///home/m/dev/pumasi/lessons/L-007-restating-a-rule-forks-it.md)):** CI checks are defined entirely within `tools/ci.sh` and invoked directly by `.github/workflows/ci.yaml`. The workflow YAML avoids defining separate inline commands, preventing configuration drift.
- **Dynamic Derivation ([`L-009`](file:///home/m/dev/pumasi/lessons/L-009-two-paths-one-claim.md)):** `tools/ci.sh` dynamically inspects [`service/tsconfig.json`](file:///home/m/dev/pumasi-booking/service/tsconfig.json), [`service/tsconfig.test.json`](file:///home/m/dev/pumasi-booking/service/tsconfig.test.json), and [`service/wrangler.jsonc`](file:///home/m/dev/pumasi-booking/service/wrangler.jsonc) at runtime so that claims about `worker.ts` and entry point bundle targets derive from actual repository state rather than hard-coded strings.
- **Fail-Fast Error Propagation:** `tools/ci.sh` mandates `set -euo pipefail` with zero error-swallowing directives (`|| true`, `|| :`, `set +e`), ensuring non-zero step failures propagate immediately to workflow exit status.

## 3. Edge Cases & Boundary Handling

- **Exclusion Drift Protection:** `A-002` asserts that `tools/ci.sh` verifies `browser-live.test.js` is present in the compiled glob before excluding it, preventing silent passes if the test is renamed or relocated.
- **Workspace Growth Protection:** `A-003` enforces that every workspace declared in root `package.json` contains a `typecheck` script, ensuring future package additions cannot be silently bypassed.
- **Privilege Boundary Defense:** `A-001` and `A-004` enforce zero `secrets.*` references, strict `permissions: contents: read`, prohibition of `pull_request_target`, and prohibition of write permissions, safeguarding public pull request execution.
- **Zero-Credential Dry Run:** Wrangler bundle verification executes purely in memory/dry-run mode without requiring Cloudflare API tokens or persistent credentials.
